# Unity MCP 操作

发现当前可用工具及其参数文档，确认服务实现和目标 Unity 工程。不同 Unity MCP 实现的工具名、资源 URI、参数和返回值可能不同，不凭旧清单构造接口。

修改前通过服务实际提供的状态资源或只读工具确认目标实例、当前场景、编译与 Play 状态。资源可用时优先读相关资源；没有资源接口时使用等价查询，不机械要求先读全部资源。

查找后使用当前查询返回的对象身份定位目标，重载或场景切换后重新核对，不复用跨会话的实例 ID。操作 Prefab、资源或场景时确认持久化范围及覆盖对象。

独立操作可在当前接口支持时批处理，依赖前一步结果的操作按依赖顺序执行。批处理不当然具备事务性或全量回滚；核对逐项结果和部分成功状态，超时先查询再重试。

脚本变更后确认本轮刷新、编译及 reload 完成，再操作新类型并读取相关编译错误。异步测试要查询最终结果；请求受理不能算通过。结果核对包括必要的状态读回、保存和真实画面，按任务影响选择。

服务不可用时报告具体缺项并继续文件层面的独立工作；可使用项目已支持的 SceneRpc 或日志作为替代。Skill 同步不安装服务，不搬运账号配置、令牌、端口或实例绑定。
