# SceneRpc 项目操作

先读项目入口指定的 SceneRpc README 和本次相关接口；未指定时定位工程中的 SceneRpcServer 与配套文档。不同项目可能有不同扩展，不照抄其他工程的 endpoint 全表。

从该工程的端口记录或已配置入口发现服务，用其实际支持的身份查询核对 projectPath 与目标工程。连接失败时检查进程、编译或 Domain Reload 状态；不要退到任意活跃实例。端口、实例 ID 与本机脚本路径不写成共享默认值。

读目标当前状态后执行必要修改。异步调用区分已接收、执行结束与实际验收；超时后先查询结果再决定是否重试，避免重复创建。批处理的依赖顺序、回滚范围和部分成功语义以当前实现为准。

改脚本后等待本次编译与 reload，再重新确认连接和目标对象。读回层级、引用与保存状态；涉及画面时核对真实截图或 Play 结果。截图缺少 Overlay UI 时选择支持该画面的捕获路径，不为截图擅自改 Canvas 渲染模式。

仅有证据显示后台节流时使用当前环境支持的恢复方法，不每次抢焦点，不默认提高进程优先级、阻止休眠或修改 PlayerSettings。需要这些设置时说明影响并沿用任务授权范围，结束恢复本次临时改变。

接口不足时先查项目既有能力；扩展服务需属于任务范围，并更新项目服务文档及相应验证。共享 Skill 只保留流程，不镜像所有项目的接口。服务安装与对外暴露不由本 Skill 自动授权。
