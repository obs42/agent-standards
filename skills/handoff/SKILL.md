# 会话交接

将当前目标、最新要求、有效决定与授权范围、已完成工作及实际验证、未解决问题和下一步写入独立 UTF-8 Markdown。使用操作系统临时目录中的唯一文件名，记录绝对路径；已有文档用链接引用，不复制会话全文或凭据。

记录当前工作区、相关分支及未提交状态，区分事实和假设，只推荐下一步真正需要的 Skill。保存后确认文件可读。

- 在 Codex 桌面且支持创建任务时，用户调用 handoff 沿用个人“创建并打开干净任务”的偏好，具体操作读 [Codex 交接流程](references/codex.md)。用户明确仅要文档时只写文档。
- 其他工具默认交付文档和简短启动提示；用户要求新会话且当前工具支持时按其实际接口创建。没有创建能力时给出可复制提示，不声称已转移任务。

启动提示包含交接文件和原工作区的绝对路径、下一步目标，要求先读交接及项目入口，再继续已授权事项；不要重新加载整段旧会话或再次触发 handoff。转移成功后停止在原会话并行修改同一任务。
