# 同步共享规则

在当前任务的项目执行，先读取项目入口及 `.agents/shared/lock.json`（存在时），确认目标项目、共享来源与跟踪版本。不要把本 Skill 所在项目误作用户指定的其他项目。

本套共享源是 `https://github.com/obs42/agent-standards.git`（私有仓库），首次接入默认使用此地址；已有 lock 时沿用项目记录，用户明确指定其他来源时再切换。电脑需要具备该私有仓库的 Git 读取权限；网页登录不等于 Git 已登录。不把令牌写入 URL、Skill 或 lock，远程读取使用 Git 已配置的认证。

使用本 Skill 自带脚本，路径为 `scripts/sync_rules.py`：

```text
python <脚本路径> --project <目标项目绝对路径> --check
python <脚本路径> --project <目标项目绝对路径> --apply
```

首次安装追加 `--source <共享仓库HTTPS地址或本地路径> --ref main`。后续默认读取 lock 的来源与 ref；提交号记录本次真实版本，本地源记录内容快照摘要。

先检查输出的差异，确保属于共享规范、没有超出请求的内容。用户说“更新/同步”即授权无冲突安装，不再机械求确认；只要求查看时不执行 apply。冲突时脚本不写入，保留本地内容并报告差异，不通过删除文件、修改 lock 摘要或强制覆盖规避检查。

脚本只分发 manifest 的文件和 AGENTS.md 标记区块，不覆盖项目 TEAM_RULES，不自动删除退休文件，不提交推送。源改动和安装副本分开：用户要修改通用规范时编辑共享源，再按授权发布；项目特例写项目规则。不得顺手同步所有项目或账号级配置。

对不读取 AGENTS.md 或不发现 `.agents/skills/` 的工具，在首次接入时核对其实际支持的入口，再加入指向本项目 AGENTS.md 的简短引用。不要声称仅复制 Skill 就能使所有工具自动识别。

结束说明源版本、更新文件、冲突与保留项。新 Skill 是否出现需在目标工具验证；当前会话已读到不等于下次会话会自动发现。
