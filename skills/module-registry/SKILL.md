# 模块文档维护

先读当前项目入口，使用其中指定的模块文档；未指定时使用项目的 `Docs/模块信息总表.md`。不把本 Skill 的安装目录当成所有任务的项目根目录。协作授权与技术约束由当前项目决定。

- 更新受影响条目的当前状态，不追加修复流水账；新模块新增条目，废弃机制说明替代关系即可。
- 按需要写用途、输入输出、关键方法与参数、流程和依赖；只补本次相关内容，不机械补全整份表格。中文解释，保留方法名，参数注明配置来源。
- 临时补丁或绕行说明存在原因、依赖前提和删除条件；正常实现不一律称作补丁。
- 过程与当次测试证据放项目指定的记录位置，不把测试历史写成永久通过保证；没有单独日志要求时，不为小改动额外造日志。
